description: Create a feature branch and commit changes in reviewable chunks
---

When working on a new feature, especially if it's a larger task, follow these steps:

1. Create a new feature branch from the current branch
2. Break the task down into smaller, manageable chunks
3. Make changes to the code for each chunk
4. Commit the changes for each chunk
5. Push the changes to the remote repository when appropriate (e.g., after each chunk or when ready to share)
