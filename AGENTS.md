# Agent instructions

Canonical agent instructions for this repository live in [CLAUDE.md](./CLAUDE.md). Read and follow that file in full — it covers Aspire orchestration, .NET Central Package Management, the CQRS/vertical-slice API architecture (`Result<T>`/`Option<T>`), xUnit v3 testing requirements, Better Auth, SvelteKit/Svelte 5 conventions, and the Git workflow.

Reusable skills are in `.claude/skills/` and repeatable workflows in `.claude/commands/`. MCP servers (Aspire, Playwright, Svelte) are configured in `.mcp.json`.
